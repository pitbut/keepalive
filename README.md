# keepalive

Один GitHub Actions workflow, который каждые 10 минут дёргает список
Render-адресов (`urls.txt`), чтобы бесплатные инстансы не засыпали
(Render "усыпляет" сервис после ~15 минут без запросов и первый
следующий запрос грузится 30-50 секунд).

## Как это работает
- Файл `urls.txt` — просто список адресов, по одному на строку.
- `.github/workflows/keepalive.yml` запускается по расписанию (cron)
  прямо на серверах GitHub — никакого отдельного постоянно работающего
  приложения не нужно и НЕЧЕМУ засыпать между запусками: GitHub сам
  поднимает раннер на 10-20 секунд, делает запросы и выключает его.

## Как добавить/убрать сайт
Просто отредактируй `urls.txt` (по одной ссылке на строку, с `https://`),
закоммить — со следующего запуска (максимум 10 минут) новый адрес уже
в списке.

## Важно: правило 60 дней
GitHub автоматически ОТКЛЮЧАЕТ scheduled-workflow, если в репозитории
60 дней подряд не было ни одного коммита (даже если сам workflow всё
это время исправно работал). Раз в 1-2 месяца просто загляни в
Actions → keepalive и, если видишь баннер "disabled", нажми
Enable workflow — либо сделай любой пустячный коммит (например,
поправь дату в README).

## Проверить вручную
Actions → Keep Render apps awake → Run workflow — запустит проверку
сразу, не дожидаясь расписания; в логе будет виден HTTP-код ответа
каждого адреса.
